Using the harness editor

Navigate

  • Drag empty space, middle-drag, or Space+drag to pan
  • Wheel to zoom, F to fit the page
  • Find box jumps to a circuit number or component

Select & edit

  • Click a component or wire; Shift+click to add; Shift+drag for a box
  • Drag components to move — attached wires follow and stay square
  • Selected wire: drag □ bends, ○ segment midpoints, ● ends (drop onto a pin to reconnect)
  • Double-click a selected wire to add a bend; click a bend then Delete to remove it
  • Drag a circuit label to slide it along its wire
  • T traces the selected wire's whole net (through splices & connectors)
  • R rotates, Ctrl+D duplicates, arrows nudge, Delete removes

Draw wires (W)

  • Click a pin to start (pins show while the tool is active)
  • Click empty space to add square bends (hold Alt for any angle)
  • Finish on a pin, or on an existing wire to splice into it
  • Double-click empty space to end on a free terminal
  • Backspace removes the last bend, Esc or right-click cancels

Saving

  • Every change is saved automatically; when signed in, it is shared live with everyone else editing
  • Use the harness menu to export JSON backups, an SVG drawing or a CSV wire list
  • Undo / redo: Ctrl+Z / Ctrl+Shift+Z
